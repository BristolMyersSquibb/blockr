# blockr 0.1.1

* Installing blockr with `pak::pak("BristolMyersSquibb/blockr")`
  now also installs blockr.ui, blockr.viz, blockr.dm, blockr.script, blockr.session and blockr.assistant.
  Attaching blockr attaches them as well.
  Every blockr package comes from its GitHub main branch,
  so the installed versions match each other (#467).
